# Examples

- `demo.data.yaml` — human-copyable resume facts (draft). Copy, edit, paste to an AI coding agent.
- `demo.polished.data.yaml` — the same demo facts after `optimize` mode: tighter verbs/length, JD fields filled, no new metrics. Compare the pair; do not treat either as a real person.
- `demo/` — official `basic-a4` template filled from `demo.data.yaml`. Open `demo/resume.html` in a browser; it is that render, not a third layout. The polished YAML is a content sibling, not a second layout.
